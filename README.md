# EN

## Welcome to PhishCheck U

WARNING: This is only a prototype, this is not a final version.

## How to use?

1. Open a terminal in the folder with the archive.
2. Paste the following command to execute it.

```bash
python name.py (replace name with the name of your archive)
```
3. Paste the message that you want to review and get your diagnostic.

## Requeriments

- Have python 3.6 or an newer version installed in your device.
- A terminal to run the program.
- It don't needs external libraries.

## Example messages to test

- Secure message example.

```text
Hi Laura, the Programming Logic class is moved to Thursday at 8 am. The slides are at http://www.uni.edu.co/materials. See you there!
```
- Suspicious message example.

```text
Hello, we noticed a login from a new device. Please verify your account within 24 hours: http://www.uni-portal.com
```
- Insecure message example.

```text
Urgent: your account was suspended. To recover access, verify your password and user in the next 24 hours: http://uni-soporte.xyz
```

- Very insecure message example.

```text
URGENT: your account was hacked and suspended! Click the link to verify and recover it within 24 hours. Enter your user, password, PIN, and the code we sent, or your credit and debit card details: http://bank-verification.top
```

python name.py (replace name with the name of your archive)

## Requeriments
